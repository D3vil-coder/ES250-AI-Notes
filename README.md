# Environmental science study guide

A single-page study guide covering environmental science topics, with chapter summaries, a two-speaker transcript view, and an exam-oriented review table. The HTML page is titled **ES200 — Mechanics of Environment**. The repository is named `ES250-AI-Notes`; the course-code mismatch has not been verified.

## Contents

The guide organizes its material into 13 chapters covering pollution and planetary boundaries, climate and eutrophication, water quality, drinking-water and wastewater treatment, solid waste, air pollution, and ozone. It also includes a transcript view with speaker filters and a review table linking topics to chapters.

The page describes its transcript grouping and speaker attribution as heuristic. Treat the guide as a study aid and verify technical facts, figures, and attribution against course materials or primary sources.

## Open locally

1. Clone this repository:

   ```sh
   git clone https://github.com/D3vil-coder/ES250-AI-Notes.git
   ```

2. Open `index.html` in a modern web browser.

There is no build step. Styles, page content and interactive JavaScript are contained in `index.html`. The page requests optional web fonts from Google Fonts; system fonts provide a fallback. Internet access is needed for those web fonts, not for a separate application server.
